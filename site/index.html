01 / INSTALLATION

Install
Twigsmith.

Choose the installation that suits you. Once installed, use twigsmith or its short name, tgi.

Requirements

Linux x86_64 with glibc 2.35+ and Git 2.45+. Editor and check commands need POSIX sh; npm installation and npx need Node.js and npm.
